# SWA — Sine Wave Analysis

非侵入式出口硬压板状态检测系统。基于 512 点原始波形 FFT 谐波分析 + 最小二乘周期投影 + 线性回归电压预测。

## 当前配方

### 1. 特征

| 特征 | 来源 | 说明 |
|------|------|------|
| `harm_a1` | FFT 基波幅值 | 核心特征 |
| `score` | 7.0+8.1 周期最小二乘投影评分 | 波形周期质量打分 |
| `temperature` | 环境温度 | z-score 归一化 |
| `humidity` | 环境湿度 | z-score 归一化 |

### 2. 预处理

- **中值滤波**：可选用（窗口 3 或 5），对原始波形扫两次，消除突变点
- **噪声过滤**：`harm_noise_pct > 0.20` 的记录被排除
- **谐波质量过滤**：`harm_a2 / harm_a1 > 0.20` 或 `harm_error / harm_a1 > 0.0008` 的记录被排除
- **削波矫正**：对指定设备（默认设备 2539）进行削波检测与锚点法 A1 补偿
- **设备映射校准**：将非基准设备的 A1 通过 `ratio(v) = a×v + b` 映射到基准设备水平
- **滑动窗口平均**：同电压连续记录按时间滑动窗口聚合（默认窗口 8），窗口内各特征取均值

### 3. 训练/测试电压分配

| 用途 | 电压 |
|------|------|
| 禁用 | ±50, ±60 |
| 训练 | ±70, ±90, ±110, ±130, ±150 |
| 测试 | ±80, ±100, ±120, ±140 |

### 4. 模型

最小二乘线性回归：

```
|Voltage| = w₀ + w₁·score + w₂·harm_a1 + w₃·temp + w₄·humidity
```

### 5. 当前性能

| 指标 | 训练集 | 测试集 |
|------|--------|--------|
| MAE | 7.006V | 6.750 V |
| RMSE | 8.966V | 8.367V |
| R² | 0.8868 | 0.8475 |
| 样本数 | 15261 | 13520 |

> 注：具体数值随数据筛选和设备配置略有浮动。以上为当前最优配置下的典型结果。
