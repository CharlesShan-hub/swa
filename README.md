# swa: Sine Wave Analysis

波形数据探索与质量分析系统 — 基于场磨式直流电场传感器波形分析，提供数据导入、波形可视化、FFT 谐波分析、质量检测等功能的桌面 GUI 应用。

## 功能

### 数据管理
- **项目导入**：从 JSONL 文件导入波形数据到 SQLite，支持按电压等级分组
- **导入稳定性处理**：每个电压等级前 N 条（默认 10）自动标记为禁用（数据不稳定期）
- **项目删除**：带重试机制的安全删除，避免文件锁问题
- **谐波预计算**：导入时自动计算 FFT 谐波参数并写入数据库

### 数据探索
- **嵌入式波形图**：点击表格行直接显示波形，同时绘制原始信号和基频拟合正弦波
- **交互式趋势图**：使用 pyecharts 生成电压/温度/湿度趋势图，支持缩放和范围滑块
- **数据筛选**：按电压等级（动态读取）、启用/禁用状态筛选
- **多选操作**：支持 Ctrl/Shift 多选行，批量启用/禁用
- **整组操作**：一键启用/禁用某电压等级的全部数据

### 波形质量检测
- **FFT 谐波分析**：对波形做 FFT 提取基频幅值 A1、二次谐波 A2、周期数
- **质量指标**：
  - **周期数**：有效波形应在 6.5~7.5 个周期
  - **总谐波失真 (THD)**：> 0.30 标记为坏数据（捕捉方波、削波、半波整流）
  - **噪声占比 (noise_pct)**：> 0.50 标记为坏数据（捕捉尖刺噪声）
  - **二次谐波比 (A2/A1)**：> 0.25 标记为坏数据
  - **拟合误差比 (error/A1)**：> 0.30 标记为坏数据
  - **基频幅值 A1**：< 1 标记为坏数据（死通道）
- **SQL 秒级检测**：一条 UPDATE 语句完成全量质量检测
- **向后兼容**：自动回填旧项目的谐波字段

### 技术栈
- **GUI**：PyQt6 + Matplotlib (QtAgg)
- **趋势图**：Pyecharts
- **信号处理**：NumPy FFT
- **数据库**：SQLite (Python sqlite3)
- **包管理**：Pixi
