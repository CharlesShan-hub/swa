# 非侵入式出口硬压板状态检测系统 — 进度与结论

## 一、项目概述

基于 512 点原始波形信号，通过 FFT 提取谐波特征，结合温湿度环境参数，使用最小二乘线性回归实现出口硬压板的非接触式电压预测。

- **技术栈**: Python 3.12+, PySide6, NumPy/SciPy, Matplotlib, Seaborn, SQLite
- **数据源**: 达梦数据库 (DM8) → 本地 SQLite
- **核心特征**: FFT 基波幅值 A1、最小二乘投影评分 (score)、温度、湿度、转速

### 2.2 检测方法

- **最小二乘法 (LS)** — 已完成并验证
  - 特征提取：FFT 谐波（harm_a1） + 最小二乘周期投影（score）
  - z-score 归一化（训练集统计 → 同步测试集）
  - 滑动窗口平均（默认 8，可配置）
  - 每电压最大样本数限制
  - 设备映射校准（默认启用，基准自动选设备 B）
  - 湿度校正（实验性，默认禁用）
  - 噪声校正（实验性，默认禁用）

### 2.3 数据管理

- 达梦数据库分批下载（支持 offset/limit，tqdm 进度显示）
- SQLite 本地存储，含 records + waveforms 双表
- 质量开关（enabled 标志位，逐条控制是否参与计算）
- 5 个预测结果缓冲区（predicted_voltage_1~5），支持多版本对比
- **电压分配持久化** — 训练/测试/禁用列表自动保存到项目目录（voltage_config.json），加载项目时自动恢复

### 2.4 特征工程

```
原始波形 (512点)
  ├─ FFT → harm_a1 (基波幅值)
  ├─ 最小二乘投影 → score (7.0+8.1周期加权)
  ├─ 环境传感器 → temperature, humidity, rpm
  └─ 归一化 → z-score (训练集均值/标准差)
```

**注**: `alpha_7` 已移除 — 与 score 高度共线性，去掉后精度不变（MAE 6.148 → 6.153）。

## 三、关键发现与结论

### 3.1 三大功臣

| # | 功臣 | 单独提升 | 累计 R² |
|---|------|---------|--------|
| 1 | **滑动窗口=8** | 0.11 → 0.49 | 0.49 |
| 2 | **设备映射校准（基准 B）** | 0.49 → 0.79 | 0.79 |
| 3 | **温湿度+RPM 特征** | 0.79 → **0.90** | **0.90** |

**最佳配置**: 窗口8 + 映射B + 全特征（score, harm_a1, temperature, humidity, rpm）

**全范围（70-150V）训练/测试结果:**

  V=+90  预测=90.3  MAE=3.46
  V=+100 预测=100.6 MAE=4.23

### 3.2 特征贡献分解

| 特征组合 | MAE | R² | 说明 |
|---------|-----|-----|------|
| 仅 harm_a1 | 11.37 | 0.68 | 基线 |
| + score | 9.20 | 0.78 | score 提供额外信息 |
| + 温湿度+RPM | **6.15** | **0.90** | **环境特征是最大功臣** |

- `alpha_7` 已被移除 — 与 score 共线性严重，去掉无影响
- `score` 和 `harm_a1` 已隐含噪声信息（corr(noise_pct, score) = -0.64）
- 湿度是环境特征中最关键的一个（A1 随湿度变化显著）

### 3.3 数据质量 > 模型复杂度

禁用脏数据（设备 253D 的 50V/60V 数据）后，简单线性回归的交叉电压预测效果大幅提升。

**结论**: 清洁数据 + 简单模型 > 脏数据 + 复杂模型。

### 3.4 湿度校正（实验性）

改进公式（带 V×H 交互项）:
```
A1_corrected = A1 - (k×|V| + γ)×(H - 40)
```
各设备独立拟合。效果有限——湿度信息已被模型通过 humidity 特征直接学习。

### 3.5 噪声校正（实验性）

```
A1_clean = A1 × (1 - noise_pct)
```
物理上合理（扣除噪声对 A1 的虚高），但由于 score 和 A1 已隐含噪声信息，对精度提升有限。

### 3.6 零信号锚点分析

全范围训练模型的零信号预测 ≈ 50V（截距 111V）。物理上合理的零信号预测需要低电压训练数据的支撑——仅用 110-150V 训练时零信号预测高达 76V。

### 3.7 设备噪声分析

三个设备的 noise_pct 相近（~0.18-0.22），但 A1 基线差异巨大（140 vs 185 vs 324）。设备间 A1 差异是传感器物理差异，不是噪声造成的。

## 五、使用流程

1. **数据库连接** → 配置 DM8 连接，下载数据到本地
2. **加载项目** → 选择项目，自动恢复上次的电压分配
3. **电压分配** → 将电压拖到训练/测试/禁用区
4. **参数配置** → 滑动窗口(默认8)、设备映射(默认开)、湿度校正、噪声校正、回填缓冲区
5. **运行检测** → 执行最小二乘回归，查看结果（表格 + 小提琴图）
6. **回填预测** → 将预测结果写入选定的缓冲区
7. **数据探索** → 在探索页查看各缓冲区的回填结果
